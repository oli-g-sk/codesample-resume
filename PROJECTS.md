## 🌍 Language Learning Apps

- An experimental suite of .NET apps with a **unique approach to getting familiar with a foreign language**. Uses **OpenAI APIs**, and consists mostly of:
  - A **Telegram Bot** that **translates** text, **transcribes** voice messages, and **speaks** to you in the language of your choosing
  - A web UI which provides **subtitles for social media content** (Reels, TikToks, YouTube) in the chosen language
  - An **ASP.NET** app serving both above use cases
  - A **desktop GUI** for further fine-tuning the translated content

## 💸 Spending Tracker

- A personal **spending tracking app with an LLM twist**. Cross-platform, made in .NET using **Avalonia**, with **backend-as-a-service** through **Supabase**.

## 🖼️ Live Wallpapers

- An **Android app turning** the user's favorite **camera roll footage into live wallpapers**, chosen at random on every screen unlock

## 🍽️ Restaurant Discovery

- An early-stage **restaurant rating** application with a unique take on the discovery experience, built on the **Java** stack with Spring Boot.

## 🏗️ Static Site Generator

- A developer-focused **static site generator** (or a .NET project template) to bootstrap a site on GitHub Pages with minimum effort, backed by **JSON content**
